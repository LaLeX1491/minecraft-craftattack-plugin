# CraftAttack Plugin

## General
This Minecraft plugin is providing functions copied from CraftAttack YouTube series.

Minecraft version: **paper 1.21.10**  
Java version: **21.0.7** (*built with temurin-21.0.7*)

## Features
- /sit command - sits the player down at the floor
- Chair listener - sits the player onto a chair / slab once right-clicking it
- /hat command - puts the item in the hand onto the head of the player
- Invisible item frames - can be crafted by surrounding an item frame with glass panes
- World deactivation - enables / disables nether or end
  - /nether <on|off>
  - /end <on|off>
